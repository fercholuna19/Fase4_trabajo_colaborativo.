Descripción del proyecto

Este proyecto consiste en desarrollar un sistema para la empresa Software FJ, que permita gestionar clientes, servicios y reservas.

El sistema permitirá registrar clientes, administrar diferentes tipos de servicios y realizar reservas, aplicando los conceptos de programación orientada a objetos y manejo de excepciones.

Objetivo

Desarrollar una aplicación organizada y funcional que permita gestionar clientes, servicios y reservas, utilizando clases, herencia, encapsulamiento, polimorfismo y manejo de errores.

Organización del proyecto

El proyecto se desarrollará por módulos para facilitar su comprensión, mantenimiento y trabajo colaborativo.
